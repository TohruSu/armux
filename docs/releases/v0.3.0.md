The first release of armux: a cmux-style terminal workspace app for Windows 11 on ARM64, built with WinUI 3 and published as NativeAOT ARM64 code.

## Install

1. Download `armux-0.3.0-win-arm64.zip` below and extract it anywhere, for example `%LOCALAPPDATA%\Programs\armux`.
2. Run `armux.exe`.

You need Windows 11 on ARM64 with the Windows App Runtime 1.8 and the WebView2 Runtime (both are usually already installed). There is no installer yet. Settings are stored in `%LOCALAPPDATA%\armux\settings.json`.

## What's in it

- **Terminals:** PowerShell 7, Windows PowerShell and cmd through ConPTY, in armux's own terminal emulator. Includes 24-bit color, scrollback, reflow on resize, mouse reporting, copy on select and bracketed paste.
- **Workspaces:** a vertical sidebar showing each workspace's title, live status, git branch, folder and unread badge. Workspaces have colors and can be pinned.
- **Panes:** split right or down, with tabs in each pane, zoom and equalize.
- **Agent notifications:** OSC 9 / 99 / 777 and the terminal bell light up pane rings, tab dots and workspace badges, and open the notification panel. A Windows toast appears when armux is in the background.
- **Taskbar status:** the current workspace's status shows on the taskbar button. It shows working while Claude Code runs, yellow when it needs you and red on error.
- **Browser:** WebView2 tabs beside your terminals. They load lazily and are suspended when hidden.
- **File explorer:** opens beside the sidebar (`Ctrl+Shift+E`). Drag a file into a terminal to type its relative path.
- **Prompt editor (`Ctrl+G`):** write a long prompt in a normal text box, then send it in one paste.
- **Settings page (`Ctrl+Shift+,`):**
  - Themes: Match Windows, Dark, Light and High contrast.
  - Fonts: Lilex and IBM Plex Sans are bundled.
  - Zoom, cursor and scrollback.
  - Start and new-tab directories.
  - Notifications and browser options.
  - Every shortcut can be rebound.
  - About shows version details.
- **`armux` CLI:** `armux notify`, `send`, `open`, `list` and `ping`. It is on the PATH in every armux terminal.
- **Safety:**
  - armux asks before closing while a terminal runs a program.
  - Enter pressed in a dialog never reaches the shell.

## Names

- The app is `armux.exe`. The CLI is `armux.com` in the same folder.
- In PowerShell and cmd, typing `armux` runs the CLI. In Git Bash, use `armux.exe notify ...`, which forwards to the CLI.

## Memory

These figures are for one PowerShell pane on a Surface Laptop 7: about 106 MB working set, 48 MB private and 27 MB in Task Manager, including the ConPTY host. Each extra pane adds about 13 MB working set, 4 MB private and 3.5 MB in Task Manager. The shell is counted separately: pwsh uses about 26 MB private. [ARCHITECTURE.md](https://github.com/apaslam09/armux/blob/main/ARCHITECTURE.md#7-memory-budget) has every scenario and the scripts to reproduce them.

## Not yet

- WSL: a WSL VM costs far more memory than armux.
- An installer, and automatic updates.

Verify the download against the `.sha256` file:

```powershell
Get-FileHash armux-0.3.0-win-arm64.zip
```
